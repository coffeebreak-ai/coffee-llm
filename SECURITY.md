# Как сообщить об уязвимости

English: do not open a public issue for a vulnerability or a leaked key. Write to the repository owner in private. The gateway is meant for loopback on one machine. Graphiti has no authentication, so do not publish port 8000.

Русский: об уязвимости и об утёкшем ключе не открывайте публичную задачу. Напишите владельцу репозитория лично. Шлюз рассчитан на петлю одной машины. У Graphiti нет авторизации, порт 8000 наружу не публикуют.

简体中文：不要为漏洞或泄露的密钥开公开议题。请私下联系仓库所有者。网关只应监听本机回环。Graphiti 没有认证，不要把 8000 端口公开到网络上。

В отчёт включите версию коммита, что вы сделали и что ожидали. Секреты пришлите отдельным закрытым каналом, не в тексте задачи.
